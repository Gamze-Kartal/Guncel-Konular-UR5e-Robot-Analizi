# Universal Robots UR5e Güvenlik ve Emniyet Analizi
Bu repo, Universal Robots UR5e işbirlikçi robot kolunun SWOT analizi, makine emniyeti ve siber güvenlik açısından incelenmesi için hazırlanmıştır.
CVE-2026-8153 kapsamında PolyScope 5'in 5.25.1 öncesi sürümleri ele alınacaktır. Değerlendirme, ilgili yazılım sürümü ve erişim koşullarıyla sınırlıdır.
Önceki KKM 725 çalışması UR5e için yeniden hazırlanmaktadır. Repo içindeki KKM 725 adlı dosyalar önceki çalışmaya aittir.
